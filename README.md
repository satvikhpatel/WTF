## 🚀 Getting Started

### Prerequisites

- A modern web browser / [required runtime or software]
- Git installed on your system

### Clone the Repository

```bash
git clone https://github.com/satvikhpatel/WTF.git
cd WTF
```

### Run a Practical

1. Open the folder of the practical you want, for example:
```bash
   cd "Practical 1"
```
2. Run or open the main file:
```bash
   # Example for web files
   open index.html

   # Example for Python / Node
   # python main.py
   # node index.js
```
